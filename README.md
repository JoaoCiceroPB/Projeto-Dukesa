# Projeto Dukesa - Landing Page Fitness 🏋️‍♂️

Landing page desenvolvida com foco no segmento fitness, estruturada a partir de estudos práticos utilizando conceitos modernos de design responsivo e componentes de interface.

<img width="1902" height="894" alt="Prévia do Projeto Dukesa" src="https://github.com/user-attachments/assets/74908e4b-84c4-44d1-9024-0a050c5d2436" />


## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização customizada e organização visual.
* **Bootstrap 5:** Framework utilitário para layout responsivo, grades (Grid System) e componentes dinâmicos (como cards e barras de navegação).
* **Flexbox & CSS Grid:** Alinhamento avançado de elementos.
* **Git e GitHub:** Controle de versão e hospedagem do código.

## 🎯 Objetivo do Projeto
Praticar a criação de interfaces web responsivas, adaptando estruturas de layout para o nicho fitness (academias, personal trainers ou plataformas de treino), garantindo uma boa experiência de navegação tanto em dispositivos móveis quanto em desktops.

## 📚 Origem do projeto

Projeto baseado em um exercício do curso Full Stack Turbo (um site de relacionamento de gatos), adaptado por mim para o nicho fitness (FitTransform).

- **O que mudei:** o tema, as cores, os textos e as imagens.
- **O que manteve:** o layout do curso.

## 🧠 O que aprendi

- Usar o **Bootstrap 5** para montar a página: grid, cards e barra de navegação.
- Deixar o layout **responsivo** para celular e desktop.
